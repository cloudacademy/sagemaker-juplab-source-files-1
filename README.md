# E179 Model Evaluation Performance Assessment

Learner content for a five-hour performance assessment using conventional phishing classifiers. No Bedrock, LLM, GPU, endpoint or container is required.

This repository is consumed by the compatible SageMaker CloudFormation template. Publish the complete content and tag **e179-v2.1** before deploying. The tagged release contains fitted Logistic Regression and XGBoost artifacts, a locked CPU environment, a student starter notebook, an environment-check notebook, datasets and assessment/report instructions.

Students work in the copied **E179** folder on their assigned instance, rather than modifying this source checkout. Read **learner/WORKSPACE_SETUP.md** and **learner/LAB_INSTRUCTIONS.md**. Wait for **E179_READY.txt**, run the workspace check, then begin the starter.

Only trusted publisher-supplied model artifacts should be loaded. Release hashes detect changes; they do not authenticate a publisher. No instructor reference notebook, assessor guide or completed answer should be placed in this public repository.
